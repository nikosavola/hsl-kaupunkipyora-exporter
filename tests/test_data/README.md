# Test Data

This directory contains anonymized test data for the HSL City Bike exporter.

## Files

- `matkahistoria.txt`: Finnish version of the ride history text content.
- `matkahistoria_en.txt`: English version of the ride history text content.
- `matkahistoria_se.txt`: Swedish version of the ride history text content.
- `matkahistoria.html`: Anonymized HTML source of the ride history page for parser testing.

These files are used by the parser tests to ensure that ride information is correctly extracted regardless of the
language settings or page format.
